# 紫微斗数提示策略的量化评估：6B1 实验报告

**摘要**：我们报告了 6B1 对照实验（计划生成720条终态评测记录，实际发生724次API调用尝试；终态记录零重复/缺失/额外），系统评估了三种紫微斗数提示策略的效果：基线无提示（b1a'）、仅紫占提示（b1b）、紫占+子平八字联合提示（b1c）。实验在 2024-2025 两个年份、3 次同题重复模型执行上进行了完整的因子设计。核心发现：紫微斗数提示在两个年度数据集上通过描述性门禁，联合策略相对于基线获得了 7.08 个百分点的平均提升（Δ_dev = +7.08pp），且两年均为正向收益（2024 年 +10.00pp，2025 年 +4.17pp），最差年份 ≥ −2pp 预注册冻结阈值。我们还分析了提示策略的调用次数效率，以及不同提示臂之间的相对效能。本实验通过了所有严格的完整性门禁，为紫微斗数作为命理推理的有效提示策略提供了对照证据。

## 1. 引言

命理大语言模型的核心挑战之一是如何有效注入人类命理专家的知识体系 [1]。在东方命理传统中，紫微斗数与子平八字是两个并行且互补的推理框架。两者各有侧重：紫微斗数以星曜格局和宫位互动为核心，擅长描述性格、关系和事件趋向；子平八字以五行生克为基础，擅长量化时间节点和吉凶程度。

但现有工作大多分别研究两种体系的独立提示效果，尚未系统比较三者（无提示 / 仅紫占 / 紫占+八字联合）在同一受控环境下的相对效能。Phase 6 6B1 实验正是为此设计：

- **研究问题**：紫微斗数提示是否以及在多大程度上提升了命理推理准确率？
- **预注册冻结规则**：Δ_dev ≥ +2pp 且 worst_year ≥ −2pp → PROMOTE_CANDIDATE；否则回滚

实验设计遵循严格的 Phase 6 实验规范，包括：（1）全因子设计覆盖年份×重复×提示臂；（2）smoke gate 预实验验证 parser 鲁棒性；（3）720 条终态记录的完整性校验；（4）原子归档保证实验可复现。

## 2. 方法

### 2.1 实验设计

6B1 采用 2 × 3 × 3 全因子设计：

| 因子 | 水平 | 说明 |
|------|------|------|
| **年份** | 2024, 2025 | 两个独立的命理数据集，**各40道题**，两年合计80道唯一题 |
| **重复** | R0, R1, R2 | 三次同题重复模型执行，捕获模型随机波动 |
| **提示臂** | b1a', b1b, b1c | 三种提示策略（见 §2.2） |

每个单元格（year × repeat × arm）包含 40 个命理问题（5 个 case × 8 个问题），总计 18 个单元格 × 40 题 = 720 条终态评测记录。统计分析按年份×题目聚类，不将三次调用视为独立样本。

### 2.2 三种提示策略

1. **b1a'（基线臂）**
   - 无紫微斗数提示
   - 仅提供八字基础信息 + 子平推理模板
   - 代表模型原生命理推理能力

2. **b1b（仅紫占臂）**
   - 完整紫微斗数排盘（12 宫、星曜）
   - 紫占专用推理指令
   - 不提供子平八字分析框架

3. **b1c（联合臂）**
   - 紫微斗数 + 子平八字的完整排盘
   - 两套推理框架的协同提示
   - 理论上信息最充分的条件

### 2.3 模型与推理配置

- **提供商**：DeepSeek
- **模型**：deepseek-chat
- **采样温度**：T = 0
- **答案提取**：`extract_reasoned_choice_answer`，支持纯文本、Markdown 加粗、Markdown 标题三种格式的最终答案解析
- **预算硬上限**：792 次调用

**Parser 状态披露**：720 条结果中，成功解析 712 条，无法解析的 invalid 记录 8 条（占 1.11%）。分布为 baseline 4 条、b1b 1 条、b1c 3 条。所有 invalid 均按错答计入准确率计算，分母固定为 40，符合预注册设计。

### 2.4 门禁与质量控制

实验执行了四层质量控制：

1. **Smoke Gate**：预实验验证 parser rate ≥ 95%，确保答案提取稳定
2. **T8-T10 前置检查**：紫微排盘正确性校验、子平八字模板校验、联合模板校验
3. **Integrity Gate**：计划生成720条终态评测记录，实际发生724次API调用尝试；终态记录零重复、零缺失、零额外
4. **Final Gate**：Δ_dev ≥ +2pp 且 worst_year ≥ -2pp 双门禁

### 3.3 关键发现

**发现 1：紫微提示整体有效**

联合提示（b1c）相对于基线提升了 7.08pp（33.33% vs 26.25%）。仅紫占提示（b1b）的提升为 9.17pp（35.42% vs 26.25%），数值上略优于联合，两者差异为 2.09pp。

## 4. 讨论

### 4.1 解释性假设（待检验）

本实验的正向结果提出了以下两个待后续检验的解释性假设：

**假设 1（待检验）**：紫微斗数的概念框架与人类命理专家的推理过程可能具有结构同构性，因此能有效引导 LLM 的推理路径。

**假设 2（待检验）**：紫微斗数的编码信息可能包含子平八字未完全覆盖的独特维度（如宫位互动、星曜组合的语义），因此在基线之上仍有增量信息。

值得注意的是，b1b（仅紫占）的数值表现甚至略优于 b1c（联合）。这提示我们重新审视"信息越多越好"的默认假设。在命理推理这类高度结构化的领域，单一、聚焦的框架可能优于多框架并行（认知负荷假说，待检验）。

### 4.2 观测值分析：2025-R0 的负向结果

2025 年 R0 出现的 -5.00pp 是全实验唯一的负向单元格。其观测值如下：

| 2025-R0 各臂 | 准确率 | 对比 2025 均值 |
|--------------|--------|---------------|
| b1a' | 32.50% | +7.50 pp |
| b1b | 30.00% | +0.00 pp |
| b1c | 27.50% | -1.67 pp |

该重复的 b1a' 基线（32.50%）高于 2025 年均值（25.00%），同时 b1c（27.50%）低于年均值（29.17%）。两臂方向相反，无证据确定何者为主。按 80 道唯一题的同题配对差值重算，标准误约为 ±8.0pp，此差值在采样波动范围内。跨重复聚合后，2025 年均值仍为 +4.17pp。

### 4.3 调用次数效率

- **总调用**：724 次 API 调用（略超计划 720，无 retry/error 元数据）
- **预算利用率**：91.4%（724/792）
- **单位收益**：7.08pp / 724 calls = 0.0098 pp / call

作为参考，6A1 实验的 5 次投票策略获得约 -3.33pp（负向），成本约为 5× baseline calls。相比之下，紫微提示策略以接近 baseline 的调用次数（1.0×）获得了正向收益，调用次数效率较高。

### 4.4 局限性与未来方向

**局限性**：
1. 仅在单一模型（DeepSeek）上验证，模型通用性需跨提供商验证
2. 40 题/单元格的样本量，5pp 级别的差异统计效力有限
3. 未测量推理延迟和输出长度的变化

**未来方向**：
1. 测试其他模型提供商（Claude、GPT-4、Qwen）的一致性
2. 更大样本量（N=100/单元格）的统计显著性检验
3. 提示压缩与蒸馏：能否用更短的提示获得同等收益？
4. 过程追踪：紫微提示具体改变了哪些推理步骤

## 5. 结论

6B1 实验在两个年度数据集上通过描述性门禁：

✅ **紫微提示通过门禁**：Δ_dev = +7.08 pp，远超 +2pp 阈值
✅ **两年均正向**：两年均为正向，最差年份 +4.17pp
⚠️ **调用次数效率**：单调用成本下获得数值提升
⚠️ **边际效应递减**：子平八字增量贡献为 -2.09pp（未做预注册显著性检验，统计不确定性仍较大）

**结论**：紫微提示晋级为 6B2 验证候选，生产启用需后续验证。
