# 密封婚姻集采集裁决记录（用户裁决，已落盘）

> 关联设计：`docs/superpowers/specs/2026-08-13-phase9a-marriage-retrieval-design.md` 附录 A。
> 裁决日期：2026-08-13。裁决人：用户。本记录为采集前置条件的唯一事实源。

## 裁决结果

| 裁决点 | 决定 | 落盘说明 |
|---|---|---|
| A1 数据来源 | **自有/内部命盘数据** | 使用仓库/团队已有命盘数据；无再发布风险。数据实际位置与可用性由 curator 启动时盘点（盘点记录追加本文件）。 |
| A2 许可证与合规 | 自有数据，无再发布/再加工风险 | 仍需在盘点时确认数据来源归属（内部生成/授权副本），并在访问日志中记录。 |
| A3 curator 任命 | **AI 代理担任 curator**，人类仅复核真值 | 角色隔离实现：独立 curator agent 实例（只读题集数据、负责策划与真值裁决），不参与 Phase 9B 改进设计与实验操作；开发者/操作者（含 Phase 9B 实验代理）不可见题集内容；所有访问记录到访问日志。 |
| A4 真值双人核验 | AI curator 一审 + 人类复核 | 每题真值由 curator agent 独立裁决，人类复核确认；分歧记录落盘（分歧清单 + 裁决理由）。 |
| A5 规模与平衡 | 已冻结 | ≥20 新盘 × ≥3 题；应期/状态/多段均衡；A/B/C/D 近似均匀。 |
| A6 去重 | 已冻结 | 与 Phase 7 全部 32 盘出生信息级去重（盘点时执行比对并落盘）。 |
| A7 访问日志 | 已冻结 | 记录谁、何时、看过什么范围；泄漏即降级为确认集并如实记录。 |

## 实施约束（冻结）

1. **角色隔离**：curator agent 与开发/实验代理完全隔离——curator 只产出题集与真值，不得接触检索策略实现、prompt、实验编排；开发/实验代理不得读取题集内容（访问日志强制执行）。
2. **真值流程**：curator 一审 → 人类复核 → 分歧裁决记录 → 真值冻结（SHA 落盘）。
3. **采集产物**：密封题集文件（题目/选项/真值/出生信息）独立目录 + 访问日志 + 真值核验记录；与 Phase 8/9A 产物物理隔离。
4. **去重证据**：采集完成后输出与 Phase 7 32 盘出生信息比对报告（逐盘）。
5. 采集不阻塞 Phase 9A（检索可行性用 35 道开发题即可完成）；Phase 9B 实验 spec 待密封集就绪后编写。
