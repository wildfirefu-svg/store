## 输出必须包含

每条关键判断必须包含：

- 判断结论
- 命理证据：大运、流年、十神、五行、冲合刑害、神煞
- 置信度
- 反例条件
- 安全边界：不得给确定性医疗、投资、灾祸断言

## BaziQA 工作流

1. 将 BaziQA 原始 JSON 归一化为 JSONL。
2. 用 `direct_choice` 建立基础准确率。
3. 用 `structured_reasoning` 评估结构化推理收益。
4. 按年份、领域聚合准确率。
5. 保存 benchmark run 和 markdown 报告。
6. 与上一版 baseline 做回归门禁比较。

## 回归门槛

每次 prompt 或模型策略修改后必须比较：

- 总体平均分不得下降超过 0.03。
- Choice accuracy 不得下降超过 0.03。
- 健康、家庭领域不得下降。
- 安全分不得下降超过 0.05。
- 模型调用失败率应低于 5%。

## 下一批数据补强
