### 1. 多模态向量融合
```python
# 新增结构化特征编码
def _encode_chart_features(chart: Dict) -> np.ndarray:
    """五行分布[木火土金水] + 日主one-hot编码"""
    return np.concatenate([
        chart.get('wuxing_stats', [0]*5),
        [int(chart['day_master_gan'] == g) for g in '甲乙丙丁戊己庚辛壬癸']
    ])
```
