# 前端 v2 设计 — 对话式分析界面

> 日期: 2026-05-22 | 基于 UX 设计迭代 v3

## 核心改动

从静态"表单→报告"改为**对话驱动的实时分析界面**，支持多命主切换和双人合婚。

## 布局

四栏布局，移动端变为单栏上下布局。

| 区域 | 展开宽度 | 折叠宽度 | 内容 |
|------|---------|---------|------|
| 命主面板 | 180px | 28px | 命主列表（点击切换/+新增/◀折叠），底部计数+管理 |
| 左·对话 | 32% | 34% | 对话区+底部👥合婚按钮+输入框 |
| 中·命盘 | 22% | 24% | 上半八字排盘表，下半紫微十二宫表 |
| 右·报告 | 40% | 42% | 标签切换+生成过程可见+修正计数 |

## 关键交互

1. **渐进式报告**：首次→新手卡片报告（Mode 5 默认，大白话）；用户要深度→四合出完整报告
2. **专题报告**：用户问财运→右侧新增"财运专题"标签；问婚姻→新增"婚姻专题"标签。各标签独立可切换
3. **自动工具调用**：Agent 根据对话内容自动判断调用工具（财运→调流年，日子→调择日，名字→调取名，合婚→调合婚）。无手动按钮
4. **实时修正**：用户指出偏差→Agent 重新推理→报告对应章节更新。"✅已纠正N处"计数
5. **生成过程可见**：报告区顶部"⏳正在生成..."状态条+闪烁光标，文字 typewriter 逐段出现
6. **公历/农历切换**+**真太阳时开关**+**日期滚轮选择器**
7. **命主切换**：左侧面板点击命主卡片切换，对话区+中间命盘+右侧报告同步更新
8. **双人合婚**：对话底部👥按钮展开合婚选择栏→选两个命主→分析→右侧生成合婚报告
9. 左侧回答简洁，右侧报告区展示详细分析

## 命主面板

| 操作 | 行为 |
|------|------|
| 点击命主卡片 | 切换当前对话命主，中间区命盘+对话上下文同步更新 |
| 点击 + 号 | 弹出出生信息表单→排盘→添加到命主列表 |
| 点击 ◀ 折叠 | 面板缩小到28px竖条，显示"命 主"竖排文字 |
| 点击 👥 按钮 | 对话框底部展开合婚选择栏，选两个命主→分析 |
| 数据存储 | sessionStorage，最多6个命盘，刷新不丢失 |

## 合婚流程

```
点击👥 → 展开双人选栏 → 选命主A+命主B → 点"分析"
→ POST /api/tools/hehun → 右侧新增"合婚"标签
→ 显示: 日主对比+日支关系+纳音+用神互补+评分卡
```

## 数据流

```
用户输入出生信息 → POST /api/chart → chart_id
→ 添加到命主面板 → 左侧简答 + 右侧新手报告

用户问"财运" → Agent判断需工具 → POST /api/tools/liunian
→ 结合流年 → 右侧新增"财运专题"标签

用户要深度 → POST /api/analyze mode=5 → 右侧新增"四合出"标签

用户选合婚 → POST /api/tools/hehun → 右侧新增"合婚"标签

用户指出偏差 → Agent重新推理 → 更新对应章节
```

## 技术方案

| 需求 | 实现 |
|------|------|
| 四栏布局 | CSS Grid `grid-template-columns: auto 32fr 22fr 40fr`（第一列由JS控制180px/28px） |
| 对话驱动 | `/api/chat`（新增端点，返回文本响应+报告更新指令） |
| 报告生成 | `/api/analyze` + `_auto_analyze()` |
| 标签切换 | JS对象 `reports: {overview, topics: {wealth, marriage, hehun}, deep}` |
| 流式输出 | SSE `/api/chat/stream` — typewriter效果 |
| 滚轮选择器 | 纯 CSS/JS 自定义组件 |
| 农历转换 | 已有 `gregorian_to_lunar()` |
| 真太阳时 | 已有 `calculate_true_solar_time()` |
| 命主存储 | sessionStorage，每个命主存 `{chart_id, birth_info, chart_summary}` |
