## 2. 分歧与裁决

### 分歧 #1 — mingli_ftb_0153（子女星判据不完整）

- **复核意见（minor）**：女命"已婚育有子女"状态题，k4 仅查 `食神` 未查 `伤官`；仓库同类题（0013 / 0098 / 0112）均为"食神+伤官"并查，0153 不一致。

### 分歧 #2 — mingli_ftb_0085（外遇主体判据不足）

- **复核意见（minor）**：2022 壬寅外遇事件题，选项区分"命主外遇"与"丈夫外遇"（答案 C=丈夫外遇被原谅）；现有桃花/咸池+婚姻断语难以单独区分外遇主体，建议补查官星被合（同 0099 离婚题模式）。
- **裁决：接受**。新增 k7 `search_shishen_combo(combo_name="官星被合")`，支撑外遇主体判别（女命丈夫 = 官星，夫星被合/入桃花主夫方外遇）。

### 分歧 #3 — mingli_ftb_0092（target_years 区间格式）

- **复核意见（备注级）**：年龄段选项（23-32 岁）换算为区间字符串 `"1984-1993"`（出生年 1961 + 23~32）；与引擎单年参数接口不直接兼容，执行时需按年展开。
- **裁决：保留区间约定**。`target_years` 支持 `"YYYY-YYYY"` 区间字符串（文档化语义：题目所问年份/范围）；P8-1.5 探针按"区间内逐年展开"执行（liunian 逐年 `current_year=Y, num_years=1`；dayun 一次覆盖区间所在大运）。此约定写入本裁决记录，供 Task 3/4 执行端遵守。
