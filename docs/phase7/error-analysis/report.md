## 3. 三项指令的直接回答

1. **婚姻类 38/44**：全题型塌陷，细粒度题型（多段/离婚 0/7、事件反查 0/3、应期 1/10）错误最干净；结论-letter 映射不是主要错误来源（仅 3/38）；未观察到低宫星覆盖在错题中富集。不能排除选项语义设计、注入内容质量或模型利用深度问题（详见 marriage_deepdive.md）。
2. **7 个全错命盘**：**未发现字段缺失或 join 故障证据**（preflight 32/32 命中、硬门第 12 条 join 全过、宫星引用率 107/107）；观察更符合"同盘题目共享推理难点"。但同率 sanity check 不显著（P=0.1292），"难盘效应"不能作为已证实结论；也不能排除内容读取深度、语义理解或官方 astro 内容本身的问题（详见 allwrong_charts.md）。
3. **错误类型**：见 §1；答案格式零故障（parser 160/160 已绿，与分类一致）。

## 4. 分析限制（诚实声明）

- shard 输入不含 chart 明细，`chart_reading` 无法逐题正向证伪。盘面引用率（匹配规则与逐题结果落盘于 quantitative_stats.json `chart_quote_rates`）：错题组宫星引用 107/107、chinese_date 引用 32/107；对题组 53/53、12/53。宫星高引用说明注入信息进入推理视野，但**引用 ≠ 正确理解**；八字块（chinese_date）引用率低，其利用深度未验证。
- 单标注者、无复核；45 题 mid 置信度。
- 首轮分类 shard-1 有 14 行 chart_case_id 手工误标，已用 normalized dataset 权威重导修正（121 字段），修正后复核零不一致。教训已记入 §6 流程项。

## 6. 密封与隔离纪律（冻结，后续实验必须遵守）

- 完整 160 题结果已看过 → 后续任何本题集分割只能称"**确认集**"，不得宣称严格 held-out；证明泛化须新增独立密封题集。
- 开发/确认分割必须按 `chart_case_id` **命盘级隔离**（同盘 4–6 题不拆两侧）。
- 分类数据的元字段（chart_case_id/category/year）一律从 normalized dataset 机械重导，禁止手工转录（本轮 14 行误标教训）。
- fetch 字节直取加固、torch 段错误修复属工程 backlog，不进入准确率实验。
