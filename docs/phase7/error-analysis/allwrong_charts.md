## 3. 盘级聚集的统计地位（v2 修正）

v1 曾用"全错盘成员富集于错题"的 Fisher 检验（p≈0）——这是**循环定义**（先按结果选盘再检验其成员），已删除。非循环 sanity check（同率零假设 + Poisson-binomial 精确尾部，落盘于 `allwrong_chart_sanity_check`）：

```text
期望全错盘 4.30 个，观察到 7 个，P(X≥7) = 0.1292 ≥ 0.05
```

**不能拒绝"各题同错误率"的零假设——盘级聚集不构成统计证据，"难盘效应"不是已证实结论。** 观察上更稳妥的表述：这 7 盘的题目集中在细粒度推断题型（case_20 全为多段婚姻/离婚细节；其余多含婚姻/应期题），与全集层面的能力短板区重叠。

## 4. 盘级推理不稳定信号（非注入问题）

- **大运排法自相矛盾**：ftb_0091 与 ftb_0092 同属 case_19，模型在两题中排出互相矛盾的大运序列（一题逆排、一题顺排）。大运由模型现场自排而非排盘引擎预计算注入。
- **地支/四化关系幻觉**：evidence 标注多题关系硬错误（"子寅相冲""申冲卯""寅卯半会""癸年武曲化忌"等），其中 2 题（ftb_0049、ftb_0075）独立归为 relation_inference。

## 5. 结论

对 7 个全错盘能下的最硬结论：**未发现注入/解析/join 故障；错误归因以学理推演为主；盘级聚集在统计上不构成显著证据。** 次级改进点：大运/地支关系改由排盘引擎预计算注入可消除盘级推理噪声（report.md C3）。
