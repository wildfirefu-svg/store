## 2. 盘级注入/解析问题 vs 知识盲区判定

判为**知识盲区为主**，依据：

1. **类别多样性**：除 case_20（4 题全婚姻）外，每个全错盘横跨 3–5 个类别。若是盘级注入/解析故障（astro 块缺失、字段错位），同类信息缺口应对所有类别产生同构错误（如盘数据张冠李戴）；实际各题错误内容各异、推理自引盘象自洽。
2. **注入信息进入推理**：宫星引用率 95/107（错题组），注入内容确实被读到；`astro_coverage_low` 与错题无显著富集。
3. **无系统性盘级异常**：7 盘的 birth_info/astro 注入核验在 preflight 已完成（32/32 命中），merged detail 行 chart_case_id join 100% 一致（硬门第 12 条）。

但有两个**盘级推理不稳定**信号（非注入问题）：

- **大运排法自相矛盾**：ftb_0091 与 ftb_0092 同属 case_19，模型在两题中排出互相矛盾的大运序列（一题逆排、一题顺排）。大运由模型现场自排而非排盘引擎预计算注入，同盘两题排法不一致 = 盘级推理噪声的直接证据。
- **地支/四化关系幻觉**：evidence 标注 5 题存在关系硬错误（如"子寅相冲""亥酉半合""子戌暗合"、误用庚干四化），其中 2 题（ftb_0049、ftb_0075）独立归为 relation_inference。

## 3. 结论

7 个全错盘**不是命盘级解析/注入故障**：注入完整、读取有引用、错误集中在学理推演层。盘级聚集（34/107 = 31.8% 的错题集中在 7/32 = 21.9% 的盘上，Fisher p≈0）的更合理解释是：**难盘效应**——这些盘的推断需要多段婚姻、应期反查等细粒度能力，而这些能力正是全集层面的缺口（婚姻 p=0.0008）。同盘题共享的是"盘难"，不是"盘错"。

次级改进点：大运/地支关系改由排盘引擎预计算注入可消除盘级推理噪声（report.md C3）。
