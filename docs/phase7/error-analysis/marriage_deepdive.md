# 婚姻类错题深潜（38/44 错，错误率 86.4%）

数据来源：`quantitative_stats.json`（题型细分）+ `error_classification.jsonl`（逐题归因，v2 复裁决后）。
题型按 question 文本规则归类（`quantitative_stats.py` buckets），归类规则已落盘可复算。

## 1. 题型细分

| 题型 | 对/总 | 错误率 |
|---|---|---|
| 多段婚姻/离婚细节（第几段、结束原因、离婚应期） | 0/7 | **100%** |
| 事件反查（X 年发生何事） | 0/3 | **100%** |
| 配偶特征 | 0/1 | 100% |
| 其他 | 0/4 | 100% |
| 应期（结婚/婚恋时间） | 1/10 | 90% |
| 感情细节（拍拖/分手/桃花） | 1/5 | 80% |
| 婚姻状况描述 | 4/14 | 71% |

结论：错误不是集中在单一题型，而是**全题型塌陷**，且越细粒度（段数、离婚年份、事件反查）错得越干净。粗粒度"婚姻状况描述"相对最好（4/14 对）。这指向**婚姻细粒度推断能力**（应期、段数、事件反查的学理推演）缺口；现有证据不能排除选项语义设计或题目难度分布的混淆作用。

## 2. 错误类型构成（v2 复裁决后）

- `knowledge` 35 / 38（92.1%）：学理推断错误。典型例（evidence_quote 为原文逐字摘录）：
  - ftb_0097：以"2007 丁亥红鸾天喜"断婚期，实际 2003（应期断错）；
  - ftb_0099：断 2015/2016 离婚，实际 2017/2018（离婚应期错）；
  - ftb_0096：断"维持第一段"，实际第二段且出轨离家（段数判断错）。
- `option_confusion` 3 / 38（7.9%）：0018/0034/0073——正文结论与最终 letter 明确冲突（如 0034 正文"故2012年结婚最符合命理"却选 B/非2012 项）。**全集 3 例 option_confusion 全部集中在婚姻类**——婚姻题选项多为年份枚举，结论到选项的映射步骤是婚姻类的次级薄弱点。
- v2 复裁决：0007、0139 由 option_confusion 改判 knowledge（正文最终结论与所选 letter 一致，错在推断本身），改判经 raw_answer 原文复核。

## 3. 选项结构

- 错题组预测 letter 分布 C 偏高：错题组 C=40/107（37.4%）vs 全题期望 C=40/160（25.0%）vs 对题组 C=9/53（17.0%）。最大混淆对：A→C 17、C→D 16、B→C 14。
- 婚姻类选项多为年份枚举，letter 偏置与"结论-选项映射错误"叠加，单独量化难以拆分，作为候选改进 C1/C4 的联合依据。

## 4. 命盘信息缺口

`astro_coverage_low`（注入盘宫星数低于中位数）在错题中**未观察到富集**（Fisher p≥0.05，见 quantitative_stats.json）。错题组宫星引用率 107/107（匹配规则落盘），注入信息确实进入了推理视野。但这只是"未观察到注入量不足的证据"——引用不等于正确理解，不能排除注入内容质量或模型利用深度问题（见 report.md §4）。

## 5. 结论

婚姻类错误的构成：**学理推断 35/38 为主，结论-letter 映射失误仅 3/38 为辅**；未观察到低注入覆盖富集于错题。对缺口性质的最硬表述到此为止，更进一步的归因（学理 vs 选项语义 vs 利用深度）需要新证据。候选改进见 report.md C1/C2。
