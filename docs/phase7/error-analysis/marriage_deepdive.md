# 婚姻类错题深潜（38/44 错，错误率 86.4%）

数据来源：`quantitative_stats.json`（题型细分）+ `error_classification.jsonl`（逐题归因）。
题型按 question 文本规则归类（`quantitative_stats.py` buckets），归类规则已落盘可复算。

## 1. 题型细分

| 题型 | 对/总 | 错误率 |
|---|---|---|
| 多段婚姻/离婚细节（第几段、结束原因、离婚应期） | 0/7 | **100%** |
| 事件反查（X 年发生何事） | 0/3 | **100%** |
| 配偶特征 | 0/1 | 100% |
| 其他 | 0/4 | 100% |
| 应期（结婚/婚恋时间） | 1/10 | 90% |
| 感情细节（拍拖/分手/桃花） | 1/5 | 80% |
| 婚姻状况描述 | 4/14 | 71% |

结论：错误不是集中在单一题型，而是**全题型塌陷**，且越细粒度（段数、离婚年份、事件反查）错得越干净。粗粒度"婚姻状况描述"相对最好（4/14 对）。这说明缺口在**婚姻细粒度推断能力**（应期、段数、事件反查的学理推演），不是某个题型的选项结构缺陷。

## 2. 错误类型构成

- `knowledge` 33 / 38（86.8%）：学理推断错误。典型证据（见 error_classification.jsonl）：
  - ftb_0097：以"2007 丁亥红鸾天喜"断婚期，实际 2003（应期断错）；
  - ftb_0099：断 2015/2016 离婚，实际 2017/2018（离婚应期错）；
  - ftb_0096：断"维持第一段"，实际第二段且出轨离家（段数判断错）；
  - ftb_0100：离婚原因取象错。
- `option_confusion` 5 / 38（13.2%）：**全集 6 例 option_confusion 中 5 例集中在婚姻类**（0007/0018/0034/0073/0139）——推理正文已推出正确或邻近结论，最终 letter 写错。这是婚姻类特有的次级信号：题干选项多为年份/状态枚举，结论到选项的映射步骤出错率高。

## 3. 选项结构

- 错题组预测 letter 分布 C 偏高：错题组 C=40/107（37.4%）vs 全题期望 C=40/160（25.0%）vs 对题组 C=9/53（17.0%）。最大混淆对：A→C 17、C→D 16、B→C 14。
- 婚姻类选项多为年份枚举，letter 偏置与"结论-选项映射错误"叠加，单独量化难以拆分，作为候选改进 C1/C5 的联合依据。

## 4. 命盘信息缺口

`astro_coverage_low`（注入盘宫星数低于中位数）与错题**无显著富集**（Fisher p≥0.05，见 quantitative_stats.json）——婚姻错题不是"盘信息给少了"导致的。宫星引用率 95/107，注入信息确实进入了推理视野。

## 5. 结论

婚姻类错误的性质：**细粒度婚姻推断的学理缺口为主（33/38），结论-选项映射失误为辅（5/38）**；与盘信息注入量无关。候选改进见 report.md C1/C2。
