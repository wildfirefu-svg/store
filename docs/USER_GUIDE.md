# 八字命理智能体 — 客户使用指南

> 版本 v2.2 | 2026-05-22

---

## 一、智能体概述

本智能体是一款基于大语言模型的**八字排盘与多体系深度解读系统**。用户输入出生信息后，自动完成八字排盘及紫微斗数排盘，支持 **6 种分析模式**，输出结构化 PDF 报告。

### 支持的分析体系

| 编号 | 体系 | 擅长领域 | 适合人群 |
|------|------|---------|---------|
| ① | 子平真诠 | 格局成败、人生层次、行运走向 | 想了解命运格局的人 |
| ② | 滴天髓 | 五行流通、命局真假、体用关系 | 关注性格五行平衡的人 |
| ③ | 紫微斗数 | 十二宫全维度、大限流年 | 需要全面人生分析的人 |
| ④ | 盲派 | 具体事件预测、财官实战 | 关注具体财运/事业的人 |
| ⑤ | 四合出 | 四体系交叉验证 | 追求最准确结论的人 |
| ⑥ | 合婚 | 双人八字配对分析 | 婚前咨询/情侣 |

## 二、使用步骤

### 第一步：提供出生信息

您只需要告诉智能体以下信息：

```
- 出生日期：1993-07-15（公历）
- 出生时间：14:30（下午2点半）
- 性别：男
- 出生地：北京（可选，用于真太阳时校正）
```

> **注意**：如果只知道农历日期或时辰（如"午时"），也可以提供，系统会自动转换。

### 第二步：选择分析模式

告诉智能体您想用哪种体系分析。如果不确定，可以说"综合看看"，智能体会推荐最合适的模式。

**快速选择指南**：

| 您想问的问题 | 推荐模式 |
|-------------|---------|
| "我命怎么样？格局高不高？" | ① 子平真诠 |
| "我五行平衡吗？性格如何？" | ② 滴天髓 |
| "全面看看各方面" | ③ 紫微斗数 |
| "什么时候发财？该不该投资？" | ④ 盲派 |
| "从多个角度分析" | ⑤ 四合出 |
| "我俩合不合适？" | ⑥ 合婚 |

### 第三步：等待分析完成

智能体会自动：

1. **排盘**（< 1 秒）：计算您的八字四柱、大运、紫微斗数
2. **校验**（自动）：交叉验证干支/十神/神煞的准确性
3. **分析**（10-30 秒）：按您选择的体系进行深度解读
4. **生成报告**：输出结构化的 Markdown 报告
5. **转 PDF**（< 2 秒）：生成排版精美的 PDF 文件

### 第四步：查看报告

报告会保存在 `reports/您的姓名_出生日期/` 目录下，包含：

```
reports/张三_1993-07-15/
├── 八字排盘_1993-07-15.json          ← 原始排盘数据
├── 子平真诠_格局命理深度报告.md       ← 可编辑的文本报告
└── 子平真诠_格局命理深度报告.pdf      ← 排版精美的PDF报告
```

## 四、自助工具

所有工具均支持 `--chart chart.json` 传入排盘数据（推荐），也支持原始出生参数。

### 4.1 个人化择吉 (zeri.py v2)

4 层评分：建除十二神 + 八字互动 + 喜用神 + 四离四绝。自动推断喜用神。

```bash
python knowledge-base/zeri.py --year 2026 --month 6 --purpose 结婚 --chart chart.json --top 10
```

### 4.2 流年日历 (liunian_calendar.py v2)

12 月运势：干支/十神/冲合/大运互动 + 4 维评分(事业/财运/感情/健康)

```bash
python knowledge-base/liunian_calendar.py --chart chart.json --target-year 2026
```

### 4.3 姓名匹配 (name_analysis.py)

7 维评测(五行/五格/三才/音韵/字义) + 取名推荐。评级 S/A/B/C/D。

```bash
python knowledge-base/name_analysis.py --name 张伟 --chart chart.json --text
python knowledge-base/name_analysis.py --generate --surname 张 --chart chart.json --gender male --top 10
```

### 4.4 合婚分析 (hehun.py)

四法合参：纳音 + 日柱 + 十神 + 用神互补

```bash
python knowledge-base/hehun.py --chart1 m.json --chart2 f.json -o report.json
```

### 4.5 八字穿壬 (chuanren.py)

大六壬天地盘 + 四课 + 三传，与八字日柱交叉分析

```bash
python knowledge-base/chuanren.py --chart chart.json --qyear 2026 --qmonth 6 --qday 1 --qhour 10
```

### 4.6 Web API

启动 API 服务器后通过 HTTP 调用所有功能 (10 个端点)

```bash
python api_server.py
# 打开 http://localhost:8000/docs 查看 Swagger 文档
```

## 五、常见问题

**Q: 不知道具体出生时间怎么办？**
A: 可以提供大概时间（如"早上"、"中午"），或告诉智能体您的重要人生事件，系统可以倒推时辰。

**Q: 农历日期可以用吗？**
A: 可以，系统自动进行农历到公历的转换（支持 1900-2100 年）。

**Q: 报告准确吗？**
A: 排盘准确率 100%（经过 5,000+ 用例验证）。解读内容基于经典命理理论，标注了出处，仅供文化参考。

**Q: 可以同时分析多个人吗？**
A: 可以。智能体支持合婚分析（一次分析两人），也支持切换不同人的命盘。

**Q: 数据安全吗？**
A: 您的出生信息仅在当前会话中使用，会话结束后系统不存储个人数据。

**Q: 报告可以分享吗？**
A: 可以。PDF 报告是标准格式（4 套模板可选），可以直接发送给他人查看。

**Q: 可以提供 Web 服务吗？**
A: 可以。执行 `python api_server.py` 启动 REST API，通过 HTTP 调用所有功能。

**Q: 名字不好可以改吗？**
A: 系统支持取名推荐和已有名字评测，输入八字命盘即可获得匹配建议。
