网站化路径：B+C 分阶段实施

目标：八字命理分析网站 | 策略：B打底 → C渐进

三阶段路线图

Phase 1: 后端地基（~2周） — 来自方案B
◻ Agent/Prompt 分离核心规则 → JSON schema → 模板外置。Agent只需加载核心规则+模式指针
◻ SQLite 知识库索引12个JSON → 1个SQLite db。统一schema，全文检索+字段查询
◻ ChromaDB 案例向量检索39例 → 向量化嵌入，语义相似度检索（需本地embedding模型）
◻ 统一 JSON API排盘/分析/择日/流年/取名 → 标准化 REST 接口
交付物可用的后端 API，postman/curl 可直接调用

Phase 2: Web服务层（~1周） — 进入方案C
◻ FastAPI Web 服务异步API + Swagger文档 + 文件上传
◻ 报告 HTML 模板Jinja2渲染，4套视觉风格，响应式布局
◻ 用户会话管理Session/cookie，命盘缓存，分析历史
◻ PDF 在线生成report_to_pdf.py 集成到API，一键下载
交付物可直接部署的网站，浏览器访问

Phase 3: 前端+高级（~2周） — 方案C完整形态
◻ Vue/React SPA 前端命盘输入→分析→报告→下载，全流程Web界面
◻ 知识图谱可视化五行生克/十神关系/大运流年 → D3.js 交互图
◻ 用户系统+持久化注册/登录 + PostgreSQL命盘库 + 分析历史
◻ 批量分析+对比多命盘对比、合婚报告、金标案例浏览
交付物完整SaaS级八字分析平台

关键架构决策

技术栈（推荐）

  • 后端: FastAPI + Python 3.14
  • 数据库: SQLite (知识库) + PostgreSQL (用户数据，可选)
  • 向量库: ChromaDB (本地嵌入)
  • 前端: Vue 3 + NaiveUI
  • 部署: Docker + Nginx

模块边界

  • calculator: 纯计算，无状态，输入→输出
  • analyzer: Agent逻辑→Python函数，可缓存
  • knowledge: SQLite查询，毫秒级
  • reports: Jinja2模板，HTML/PDF双输出
  • api: FastAPI路由，薄封装层

推荐从 Phase 1 开始。完成后立即可验证 API 是否正常工作，再决定是否继续后续阶段。
