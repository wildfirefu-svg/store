设计决策

决策选择理由
三栏比例42% / 16% / 42%对话和报告同等重要，中间栏放命盘摘要+快捷工具
对话驱动报告每次对话响应都带上完整报告更新报告始终是最新状态，用户不需要手动刷新
修正机制用户指出偏差 → Agent 重新推理 → 覆盖特定章节只改被纠正的部分，不改其他章节
中间栏命盘摘要 + 模式切换 + 工具入口始终可见，方便快速切换
对话历史保存在 sessionStorage刷新页面后对话不丢失
初始输入对话的第一条消息就是出生信息自然语言输入，不需要分页跳转

移动端：三栏变为单栏，对话在上，报告在下，中间栏折叠到顶部导航
