设计要点总结

需求实现
1. 35/25/40 比例左对话 35%，中命盘 25%，右报告 40%
2. 中间区上下分上半：八字排盘表 + 日主/格局/用神/大运/五行；下半：紫微十二宫表
3. 取消手动按钮Agent 根据对话内容自动判断：问财运→调流年工具，问日子→调择日工具，问名字→调取名工具
4. 渐进式报告初次→新手卡片报告；用户要深度→四合出完整报告。右侧标签栏可切换
5. 专题报告问财运→生成"财运专题"标签；问婚姻→生成"婚姻专题"标签。各标签独立，可切换
6. 生成过程可见报告区顶部显示"⏳ 正在生成..."状态条 + 闪烁光标，文字逐段出现（typewriter效果）

数据流

用户输入出生信息 → POST /api/chart → 返回 chart_id
→ 左侧显示简答 + 右侧渲染新手报告（/api/analyze mode=5 默认）

用户问"财运" → Agent 判断需调工具 → POST /api/tools/liunian
→ 结合流年数据生成财运专题 → 右侧新增"财运专题"标签

用户要深度报告 → Agent 调四合出分析
→ POST /api/analyze mode=5 → 右侧新增"四合出"标签

用户指出偏差 → Agent 接收纠正 → 重新推理 → PUT 更新报告对应章节
